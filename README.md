- **프론트앤드 응용 (React/Next.js)**
  1. 이전 프론트엔드 과정에서 제작한 Todo 리스트를 Next.js 기반으로 개발 합니다.
  2. 회원가입 및 로그인 기능을 추가하여 회원 전용 Todo 리스트를 구현합니다.
  3. 회원 정보 및 할 일 데이터는 Supabase를 연동하여 관리합니다.
  4. 완성된 코드는 개인 GitHub 저장소(Repository)에 커밋·푸시한 뒤, 해당 저장소 주소(URL)를 제출합니다.
  5. GitHub와 Vercel을 연동하여 프로젝트를 배포하고, 실제 서비스 배포 주소(URL)를 함께 제출합니다.
